# The Alignment Lab

Interactive laboratory for testing AI decision rules, constraints, fairness trade-offs, and objective alignment.

## Analysis

- **Core experience:** scenario library, rule architect, laboratory, adversarial testing, fairness observatory, and decision-trace views.
- **Technical approach:** React + TypeScript + Vite, typed decision models, rule evaluation engine, scenario state, local storage, and traceable outcomes.
- **Portfolio value:** communicates responsible-AI thinking through a tangible, inspectable interface rather than a static essay.
- **Current health:** production build and TypeScript check pass. ESLint reports existing unused symbols and one empty-interface rule violation.

## Run locally

```bash
npm install
npm run dev
```
